# Матч-центр | Теннис

Расписание и счёт мужских и женских матчей из ESPN и трансляции из каналов VK Видео в одном окне.
Под каждым матчем — кнопки каналов; в приложении плеер VK открывается отдельным окном. Разряды и каналы
настраиваются: можно добавить любой канал VK Видео.

Windows 10/11, x64. Работает без аккаунтов и токенов. Трансляции доступны только с российского IP.

Сделан из футбольного «Матч-центра» и живёт отдельно от него: своё имя, своя папка настроек,
оба приложения можно держать рядом. Что сделано и что осталось — в [PLAN.md](PLAN.md).

## Возможности

### Расписание

- **Полоса дат** — семь дней, при запуске сегодня в середине. **‹** **›** и клавиши **←** **→**
  переключают на день назад или вперёд. Листать можно от 10 дней назад до 10 дней вперёд.
  В полночь «Сегодня» само переходит на новый день.
- **Турниры** — доступные в ESPN турниры, которые идут в выбранный день. В настройках выбираются
  **разряды**: «Мужчины» и «Женщины»; одиночные включены, парные по умолчанию выключены.
  В табло также входят четыре турнира **Большого шлема**: Australian Open, Roland Garros,
  Wimbledon и US Open. Отдельный источник ITF для них не требуется. Мужские сетки
  показываются в «Мужчины», женские — в «Женщины» по меткам разряда ESPN; микст не включён.
- **Уровень турнира** — в шапке раздела: Grand Slam, ATP Finals / WTA Finals, ATP / WTA 1000,
  500 и 250. Показываются только турниры этих уровней; WTA 125, Next Gen ATP Finals и командные
  турниры скрыты. Уровень берётся из справочника сезона (см. «Как это работает»); если
  справочника на сезон ещё нет, показываются все турниры ESPN, а метка есть только у Шлемов.
  По уровню можно искать: «500», «WTA 1000».
- **День — по часам компьютера.** Ночной матч в Америке стоит в том дне, на который он
  приходится у вас. Идущий матч, начатый до полуночи, остаётся и в сегодняшнем списке.
- **Порядок.** Обычно разделы идут один за другим: турнир за турниром, сначала одиночные
  разряды, потом парные. Кнопка с часами в шапке ставит матчи **по времени начала**.
  Выбор запоминается.
- **Счёт по сетам** обновляется сам (с задержкой до минуты): геймы в каждом сете, очки
  тай-брейка мелко сверху, точка у подающего; выигранные сеты и победитель матча выделены. Счёта внутри гейма нет.
- **Статус**: время начала, номер идущего сета, «Оконч.», «Отказ», «Неявка», «Отмена», «Перенос».
  Если время ещё не назначено («после предыдущего матча»), вместо него прочерк;
  такие матчи стоят в конце списка.
- **Под названием турнира** — раунд и корт; перед именем игрока — номер посева.
- **Имена игроков** — как в ESPN, на английском.
- **Сейчас в эфире** — блок над расписанием (для сегодняшнего дня) с матчами, которые идут
  и у которых есть живая трансляция.
- **Фильтры** «С трансляцией», «Идут сейчас», «★ Избранное» и **поиск** по игроку или турниру
  (игрока можно искать и по-русски). Фильтры запоминаются.

### Трансляции

- **Каналы** по умолчанию: ПраймСпорт, Sportcast Теннис, BB Tennis, Больше! Теннис,
  Теннис Тайм. Можно добавить любой канал VK Видео.
- **Метки**: **LIVE** — идёт сейчас, рядом число зрителей; **скоро** — запланирована;
  **запись** — закончилась.
- **Порядок кнопок**: идущие всегда впереди, дальше запланированные, затем записи.
  Несколько эфиров одного канала нумеруются: «Sportcast Теннис», «Sportcast Теннис 2».
- Наведите на кнопку — увидите полный заголовок эфира. Если трансляций у матча нет —
  кнопка «Искать в VK».

### Плеер

- Клик по каналу открывает официальный плеер VK **в отдельном окне поверх остальных**,
  с пропорциями 16:9. Можно открыть несколько матчей. Закрывается крестиком самого окна.
- Первое окно открывается с громкостью **50%**, второе и последующие — **без звука**.
  Громкость и звук можно менять в самом плеере. После закрытия всех окон следующая
  трансляция снова открывается на 50%; закрытие первого окна само не включает звук в остальных.
- Плеер открывается в режиме VK **«Высокое качество»** (вместо «Автоматически»).
  Качество можно сменить в меню плеера; выбор действует до выхода из приложения.
- Обновление расписания и фильтры не перезагружают видео. Записи открываются с начала;
  позиция просмотра после закрытия окна не сохраняется.
- **Ctrl + клик** по каналу открывает эфир во внешнем браузере.
- Приложение работает в Electron; отдельный браузерный режим не поддерживается.
  VK может показывать в нём «Видео недоступно»; тогда используйте «Открыть в VK ↗».

### Без спойлеров

- Кнопка «Без спойлеров» рядом с фильтрами прячет счёт, победителя и подающего — чтобы
  смотреть запись, не зная результата. Счёт одного матча открывается нажатием на **?**.

### Избранное и уведомления

- **★** рядом с игроком (в одиночном разряде) — игрок в избранном: напоминания обо всех его
  матчах, в том числе парных.
- **🔔** под временем начала — напомнить об одном матче.
- **Уведомления Windows**: **за 15 минут** до начала по расписанию и **когда матч начался**.
  Время в теннисе условное, поэтому начало ловится по самому матчу: пока он задерживается,
  приложение проверяет его раз в минуту. Клик по уведомлению открывает матч, а если
  трансляция идёт — сразу и плеер.

### Трей и автозапуск

- Крестик окна **прячет приложение в трей** — уведомления продолжают приходить. Выйти — правой
  кнопкой по значку → «Выход» или **Ctrl+Q**. Трей можно выключить в настройках.
- **Запуск вместе с Windows** (выключен по умолчанию) — приложение стартует свёрнутым в трей.

### Клавиши

| Клавиша | |
|---|---|
| **←** **→** | предыдущий / следующий день |
| **/** | поиск; **Esc** в поиске очищает запрос |
| **R** | обновить каналы и расписание |
| **,** | настройки |
| **Esc** | закрыть панель каналов |
| **Ctrl + клик** по каналу | открыть трансляцию в браузере |
| **Alt** | показать меню приложения |
| **Ctrl+Q** | выйти из приложения |

## Настройки

Всё меняется в окне настроек (кнопка справа вверху или **,**):

- **каналы** — добавить по ссылке `vkvideo.ru/@name`, переименовать, выключить встроенный,
  удалить добавленный;
- **разряды** — «Мужчины» и «Женщины»; парные по умолчанию выключены;
- **частота опроса каналов** — от 30 секунд до 5 минут;
- **уведомления**, **трей**, **запуск вместе с Windows**;
- **написание игроков** — если эфир не привязался к матчу, потому что канал пишет игрока
  по-своему: `Соболенко = Сабаленка` или, для игрока без русского имени в словаре,
  `Samson = Самсон`.

Файл — `%APPDATA%\TennisCenter\settings.json` (**Alt** → меню → «Папка с настройками»).
В нём хранятся **только отличия** от встроенных настроек. Если правите руками — выйдите из
приложения (из трея), иначе оно перезапишет файл при следующем сохранении.

```json
{
  "channels": [
    { "screenName": "my_channel", "label": "Мой канал" },
    { "screenName": "bbtennis_live", "disabled": true }
  ],
  "leagues": [2, 1, 4],
  "teamAliases": { "Соболенко": ["Сабаленка"] },
  "refreshSeconds": 120,
  "favorites": [{ "id": 9820, "name": "Mirra Andreeva" }],
  "ui": { "theme": "dark", "hideScores": false, "leaguesByTime": true }
}
```

`leagues` — разряды и их порядок: 1 — мужчины одиночный, 2 — женщины одиночный,
3 — мужчины парный, 4 — женщины парный.

## Отчёт для диагностики

Если что-то не работает, нажмите на индикатор каналов VK в шапке → **«Скопировать отчёт»**
(или **Alt** → меню → «Скопировать отчёт для диагностики») и вставьте текст в сообщение
о проблеме. В отчёте:

- версии приложения, Electron и ОС, установленная это версия или запуск из исходников;
- ESPN по каждому туру: время последнего успешного ответа и последней ошибки;
- каждый канал VK: работает ли, каким способом прочитан, когда проверен и когда были
  последние данные, неудачи и пауза запасного чтения, текст ошибки;
- предупреждения и только **счётчики** настроек: сколько каналов, разрядов, избранного.

В отчёт не попадают пути с именем пользователя (заменяются на `<userData>`, `~`, `<user>`),
параметры адресов, токены, e-mail и содержимое настроек: имена избранных игроков, свои
написания, отмеченные матчи. Добавленные вами каналы обозначены как «свой канал 1».
Время в отчёте — UTC.

## Как это работает

**Расписание и счёт** — неофициальный API табло ESPN (`site.api.espn.com`), без ключа. Запрос
«на день» возвращает целиком турниры, идущие в этот день по американскому времени; нужный день
приложение выбирает само, а чтобы не потерять ночные матчи, спрашивает ещё и соседние дни.
Идущие матчи обновляются раз в минуту. Если ESPN не ответил, показывается расписание,
полученное ранее. Челленджеров и ITF в табло ESPN нет.

**Уровни турниров** ESPN не отдаёт (только признак Шлема), поэтому в приложении есть справочник
`src/core/tournaments.json`: для каждого сезона и тура — номер турнира ESPN (часть `id` до
дефиса, например `970` в `970-2026`), уровень и название для удобства правки. Справочник
составлен по календарям сезона в Википедии (ссылки — в поле `source`) и правится вручную раз
в год, когда выходит календарь следующего сезона. У общего турнира уровни мужчин и женщин
разные (Брисбен: ATP 250 и WTA 500), поэтому туры записаны отдельно.

**Каналы VK** читаются раз в минуту (настраивается). Приложение делает те же запросы к API
VK Видео, что и сайт для незалогиненного посетителя. Каждую минуту читаются свежие эфиры
и те, что идут или ожидаются в ближайшие сутки; остальное (записи примерно за месяц и
эфиры, назначенные позже) — раз в 15 минут. Если API не ответил, канал читается
запасным способом — страница открывается в скрытом окне.

**Привязка трансляции к матчу** — по именам игроков в заголовке. Игроки ищутся в любой части
заголовка между `|` или ` / `; между ними может стоять тире, дефис, `vs`, «против» или `x`.
Каналы пишут по-русски, ESPN — по-английски, поэтому в приложении есть словарь русских имён
(`src/core/players.json`: топ-150 ATP и WTA и часть парников); остальных оно узнаёт,
переводя заголовок в латиницу. Лишние слова отсекаются, опечатки прощаются. Пара привязывается,
только если в заголовке есть оба игрока каждой стороны. Учитываются эфиры, созданные от двух
суток до матча до двенадцати часов после его начала по расписанию.

**Сеть.** Приложение обращается только к ESPN (`site.api.espn.com`, флаги — `a.espncdn.com`),
VK (`login.vk.ru`, `api.vkvideo.ru`, `vkvideo.ru`) и GitHub (обновления). Никакой статистики
не отправляет. Внутри приложения работает локальный сервер только на `127.0.0.1`.

**Россия.** VK отдаёт эти каналы только на российский IP.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Трансляций нет, точка у «N эфиров» красная | Нужен российский IP — выключите VPN или смените страну |
| В плеере «Видео недоступно» | Откройте эфир во внешнем браузере через Ctrl + клик по каналу |
| Трансляция есть на канале, но не под матчем | Добавьте написание игрока в настройках; пока — «Искать в VK» |
| Матча нет в расписании | Это челленджер или ITF — их нет в ESPN; либо выключен его разряд |
| Счёт или эфиры кажутся устаревшими | Кнопка **↻** или клавиша **R** |
| «ESPN (или VK) изменил формат ответа» | Сайт поменял свои данные, и эта версия их не понимает — нужна новая версия приложения |

## Запуск из исходников

Нужен Node.js 22+.

```
npm install
npm run app
```

Из исходников приложение использует отдельный профиль `%APPDATA%\TennisCenter-dev`.

Проверки: `npm test` — ядро и модули страницы; `npm run smoke` — само приложение (окно, трей,
прямые окна плеера, настройки, выход) на подставных данных в отдельном
временном профиле.

На каждый PR и push в `main` GitHub Actions запускает те же проверки на Windows
([.github/workflows/ci.yml](.github/workflows/ci.yml)): `npm test` на Node.js 22 и 24
и `npm run smoke`. Настоящие ESPN и VK в CI не проверяются — сеть там подставная.

`npm run dist` собирает установщик в `dist/`: `tennis-center-X.Y.Z-setup.exe`. Версия берётся
из `package.json`.

Иконка теннисного мяча хранится в `src/assets/icon.png` и `icon.ico` (16–256 px).
Исходник — `scripts/make-icon.ps1`; пересоздание в Windows:
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/make-icon.ps1`.
