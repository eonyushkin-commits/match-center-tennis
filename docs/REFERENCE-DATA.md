# Справочники: как обновлять

Два файла в `src/core/` правятся вручную. Их форму проверяет `test/reference-data.test.mjs`
(входит в `npm test` и CI): после правки запустите `npm test`.

## Уровни турниров — `tournaments.json`, раз в год

ESPN не сообщает уровень турнира (только признак Большого шлема), поэтому уровни берутся
из справочника сезона. **Пока сезона в файле нет, приложение показывает все турниры ESPN**
без фильтра (в том числе WTA 125 и командные), а метку уровня — только у Шлемов. Поэтому
новый сезон нужно добавить до первых турниров января — в декабре, когда опубликованы
календари туров.

### Что входит

Только турниры, которые показывает приложение (решение пользователя):

- ATP: Grand Slam, ATP Finals, ATP 1000, ATP 500, ATP 250;
- WTA: Grand Slam, WTA Finals, WTA 1000, WTA 500, WTA 250.

Не входят: WTA 125, Next Gen ATP Finals, командные турниры (United Cup, Davis Cup,
Billie Jean King Cup и т. п.), челленджеры. Скрытие Next Gen и WTA 125 — решение агента,
пользователь его пока не подтвердил (см. PLAN.md).

### Формат

```json
{
  "2027": {
    "source": ["https://en.wikipedia.org/wiki/2027_ATP_Tour", "https://en.wikipedia.org/wiki/2027_WTA_Tour"],
    "atp": [{ "id": "4", "level": "ATP 500", "name": "Rotterdam Open" }],
    "wta": [{ "id": "…", "level": "WTA 1000", "name": "…" }]
  }
}
```

- Ключ — год сезона. У турнира ESPN номер вида `4-2027`: `id` — часть **до** дефиса,
  год берётся из части после дефиса.
- Туры раздельно: у общего турнира уровни разные (Брисбен — ATP 250 и WTA 500).
- Один турнир может иметь у ESPN два номера (Лион в 2026: `110` с сетками и `452` без) —
  в справочник идут оба.
- `name` — для человека; приложение показывает название из ESPN.

### Порядок

1. **Календарь.** Взять страницы `YYYY_ATP_Tour` и `YYYY_WTA_Tour` из Википедии (удобно
   в виде wikitext: `https://en.wikipedia.org/w/index.php?title=2027_ATP_Tour&action=raw`)
   или календари с atptour.com / wtatennis.com. Выписать турниры нужных уровней.
2. **Номера ESPN.** Скопировать прошлый сезон как основу: номера турниров ESPN обычно
   не меняются от года к году, но это нужно проверить. Для нового или сомнительного
   турнира взять номер из табло в неделю турнира:
   `https://site.api.espn.com/apis/site/v2/sports/tennis/atp/scoreboard?dates=YYYYMMDD`
   (для женщин — `/wta/`): `events[].id` и `events[].name`. Номер должен встречаться
   в табло своего тура и содержать сетку своего пола (`mens-singles` / `womens-singles`).
3. **Уровни.** Сверить уровень каждого турнира с календарём: турниры меняют категорию
   (500 ↔ 250), появляются и исчезают.
4. **Проверка.** `npm test` — тест проверит номера, уровни, четыре Шлема и один итоговый
   турнир в каждом туре, длину календаря (40–80). Затем `npm run app` и пролистать
   2–3 даты нового сезона, когда в табло ESPN появятся турниры: нужные турниры видны,
   у каждого метка уровня, WTA 125 нет.
5. В `source` — ссылки на использованные календари. В PLAN.md — запись о проверке.

Старые сезоны из файла не удалять: по ним показываются прошлые даты.

## Русские имена игроков — `players.json`, по мере надобности

Каналы VK пишут игроков по-русски («Андреева — Шнайдер»), ESPN — по-английски. Словарь
`номер ESPN → [имя, фамилия]` помогает привязать эфир к матчу. Игрока без словаря
приложение всё равно пробует узнать по латинице (Басаваредди → basavareddi), поэтому
добавлять нужно не всех, а тех, у кого эфир не привязался.

- **Признак:** у идущего матча нет кнопки канала (только «Искать в VK»), хотя на канале
  VK эфир с этими игроками есть.
- **Номер ESPN:** в табло ESPN (адрес — выше) у одиночного матча это `competitors[].id`,
  у пары — `/id/<номер>/` в `competitors[].roster.athletes[].links[0].href`
  (так его берёт `src/core/day.mjs`).
- **Запись:** `"9820": ["Мирра", "Андреева"]`. Имя может быть пустым (`["", "Буюньчаокэтэ"]`).
  У китайских имён встречается третий элемент `1` (порядок «фамилия имя»); кодом он
  сейчас не читается, новые записи можно добавлять без него.
- Написание — как у каналов VK. Если каналы пишут по-разному («Баэс» / «Баес»), это
  учтено автоматически (э → е); для других вариантов — `teamAliases` в `defaults.json`.

Пользователю правка файла не нужна: в настройках есть «Написание игроков»
(`Соболенко = Сабаленка`), это сохраняется только у него.

## Каналы и написания по умолчанию — `defaults.json`

`channels` — встроенные каналы VK (`screenName` из адреса `vkvideo.ru/@name` и подпись),
`teamAliases` — общие варианты написания игроков. Изменения доходят до всех пользователей
с новой версией: в настройках пользователя хранятся только его отличия.
