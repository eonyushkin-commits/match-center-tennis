# Проверка перед релизом

Автоматические проверки (`npm test`, `npm run smoke`, CI) работают на подставной сети и не
видят изменений настоящих ESPN и VK, установщика и автообновления. Этот список проходится
вручную перед публикацией релиза. Результат — какие пункты пройдены, а какие нет и почему —
записывается в [PLAN.md](../PLAN.md), в таблицу проверок.

Нужно: Windows 10/11 x64, российский IP (иначе VK не отдаёт эфиры), идущий или недавний
теннисный матч с трансляцией на одном из встроенных каналов.

## 1. Автоматика

- [ ] `npm test` и `npm run smoke` проходят локально; CI на PR зелёный.
- [ ] Версия в `package.json` и `package-lock.json` повышена.
- [ ] `npm run dist` собран из merge-коммита в `main`; SHA512 и размер exe совпадают
      с `dist/latest.yml`; файлы `src` в `app.asar` совпадают с этим коммитом.

## 2. Настоящие источники (запуск из исходников: `npm run app`)

- [ ] **ESPN.** Сегодняшние турниры и матчи на месте; счёт идущего матча совпадает
      с espn.com (с задержкой до минуты); внизу окна «счёт ESPN от ЧЧ:ММ» обновляется.
- [ ] **ESPN недоступен.** Отключить сеть на 2 минуты: расписание остаётся, полоса
      «ESPN сейчас недоступен — показано расписание от ЧЧ:ММ», время внизу не двигается,
      пометка «(не обновляется)». После включения сети — снова свежее время.
- [ ] **VK.** Индикатор каналов зелёный, в панели каналов все встроенные каналы «через API».
- [ ] **Привязка эфиров.** У идущего матча есть кнопка канала с меткой LIVE; у прошедших —
      записи; у матча без трансляции — «Искать в VK».
- [ ] **Отчёт.** «Скопировать отчёт» в панели каналов: в тексте версия, ОС, ESPN по турам,
      каналы; нет имени пользователя Windows, полных путей, параметров адресов.

## 3. Воспроизведение (глазами и на слух)

- [ ] Клик по LIVE открывает окно плеера поверх остальных, 16:9, видео идёт.
- [ ] Первое окно — со звуком на 50%, второе — без звука; после закрытия всех следующее
      снова со звуком.
- [ ] Качество в первые секунды не ниже 720p (меню качества плеера VK).
- [ ] Ctrl+клик по каналу открывает трансляцию в браузере.

## 4. Установка и обновление

- [ ] **Установка поверх предыдущей версии.** Поставить новый exe поверх установленной
      прежней: настройки, избранное и каналы сохранились; в заголовке окна новая версия.
- [ ] **Автообновление.** На машине с предыдущей версией после публикации релиза:
      полоса «Доступна версия X» → «Скачать» → прогресс → «Установить» → приложение
      перезапускается уже новой версией.
- [ ] **Трей и автозапуск.** Крестик прячет окно в трей; «Выход» из меню трея закрывает
      приложение; при включённом автозапуске после входа в Windows приложение в трее.
- [ ] **Уведомление.** Отмеченный колокольчиком матч даёт уведомление за 15 минут
      и при начале; клик по уведомлению открывает матч.

Пункты, которые проверить нельзя (нет идущих матчей, нет второй машины), так и
отмечаются — «не проверено», с причиной, а не пропускаются молча.
